# Portafolio · Paulina Guerrero López

Sitio estático en Astro.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # genera dist/ listo para subir a Netlify, Vercel, Cloudflare Pages, etc.
```

- Instagram, correo, bio y cifras: `src/data/site.ts`
- Videos (título, link de TikTok, portada): `src/data/videos.ts`
- Video incrustado: `public/videos/san-jeronimo.mp4`
